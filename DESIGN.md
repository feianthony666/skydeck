# SkyDeck design

SkyDeck uses a restrained instrument-panel aesthetic: cool neutral surfaces, compact system typography, high-contrast data, cyan or sky-blue for live activity, amber for warnings, and red for emergencies.

## Layout

Dense desktop tool layout with a full-viewport radar, compact top controls, an inspector dock, and bottom navigation on portrait mobile.

## Motion

Motion communicates live state. Radar zoom is immediate and smooth, while 3D camera changes glide briefly and avoid decorative animation.
